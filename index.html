Carregar os arquivos da Receita

Arraste aqui os arquivos Socios0.zip … Socios9.zip (e, se quiser os nomes sem internet, também Empresas0.zip … Empresas9.zip) ou .

Não precisa descompactar. O processamento acontece só no seu computador. Nenhum arquivo é enviado.

Como baixar os arquivos (passo a passo)
  1. Abra os Dados Abertos do CNPJ da Receita Federal (se o link mudar, procure "Dados Públicos CNPJ" em dados.gov.br).
  2. Entre na pasta do mês mais recente (ex.: 2026-10).
  3. Baixe Socios0.zip a Socios9.zip (obrigatórios). Opcional: Empresas0.zip a Empresas9.zip, para ver a razão social mesmo sem internet.
  4. Arraste todos os .zip para o quadro acima, de uma vez. Leva alguns minutos.
  5. Pronto: o índice fica salvo neste navegador. Nas próximas vezes a página já abre com a base. Atualize uma vez por mês, se quiser dados recentes.

Os arquivos de Estabelecimentos não são necessários.

2 Pesquisar

O que esta pesquisa mostra (e o que não mostra)

  • Mostra as empresas em cujo Quadro de Sócios e Administradores (QSA) da Receita o CNPJ pesquisado aparece como sócio pessoa jurídica. A comparação é feita pela raiz do CNPJ (8 primeiros caracteres), então matriz e filiais contam como a mesma empresa.
  • A Receita não publica o percentual de participação de cada sócio.
  • Em Sociedades Anônimas o QSA traz diretores e conselheiros, não acionistas. Participações em S.A. normalmente não aparecem.
  • Sócios estrangeiros sem CNPJ aparecem pelo nome, marcados como "Exterior".
  • A Receita publica os dados uma vez por mês. A base na nuvem é atualizada sozinha pelo GitHub quando sai um mês novo. Os dados online (situação, cidade) vêm da BrasilAPI ou da Minha Receita, que só recebem o CNPJ consultado.
  • Sem nenhuma base disponível, a opção Quem é dono dela ainda funciona, consultando o QSA online, nível a nível.
